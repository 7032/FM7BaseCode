# functest — 機能デモ集

FM-7 / FM77AV シリーズの各機能を、実機およびエミュレータ上で実際に
動かして確認するための小さなデモ集です。各デモは F-BASIC を使わない
2D ディスクイメージ (`.d77`) として単体で起動し、実機・WebM7・その他の
エミュレータで動作します。

## 収録デモ

| デモ | 内容 |
|------|------|
| [mouse](mouse/) | マウスカーソルデモ。バスマウス / インテリジェントマウスの両対応、画面モード切替ボタン付き。FM-7 / FM77AV / FM77AV40 / FM77AV40EX 対応 |
| [ym2203csm](ym2203csm/) | YM2203 (OPN) の CSM モードによる音声合成デモ。サンプリングではなくピッチ + 4 フォルマントのパラメータ (14 バイト/10.1725ms) で人の声を鳴らす。FM77AV / FM77AV40 / FM77AV40EX 対応 (FM-7 は非対応メッセージを表示して停止) |
| [psgvoice](psgvoice/) | PSG (AY-3-8910) だけで音声 WAV を再生するデモ。音量レジスタをサンプルごとに書き換えて PSG の音量 D/A 変換器を 4 ビット DAC として使うサンプリング再生 (11025Hz)。FM 音源は使わないので FM-7 本体のみで動作 (FM-7 / FM77AV で動作確認済み)。ディスク起動に加え `make t77` で CMT (カセットテープ) ロードにも対応 |

各デモのフォルダに、操作方法・ビルド方法を記した README、ソース、
起動用ディスクイメージが入っています。マウスカーソルデモには、
WebM7 の core 上でデモをブートして自動検証するヘッドレステスト
(`make test`) も同梱しています。
